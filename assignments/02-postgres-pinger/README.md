# Задание 2 Сервис проверки PostgreSQL (Ромашов С.П)

## Задание

1.	На основе кода разработанного в практическом занятии 1, разработать программу:
1.1.	Приложение сервис(pinger, heartbit) выполняющую функции отправки запроса версии БД  Postgresql [16, 17], раз в 5 минут.
1.2.	Факт успешного или не успешное подключения к БД должен записываться в соответствующий поток вывода stdout / stderr.
1.3.	Если БД возвращает не типичный ответ на запрос версии, но не вызывает ошибку он должен записываться в поток вывода stdout.
1.4.	Приложение не должно зависать в случае сетевых проблем, ошибки подключения не должны отменять проверку через следующие 5 минут.
1.5.	Интервал между опросами (5 минут) должен задаваться через переменные среды окружения.
1.6.	Логин и пароль необходимый для подключения к БД теперь должны получаться через переменные среды окружения.
1.7.	Приложению через переменную среды окружения, дополнительно можно передать путь к файлу, куда будут дублироваться логи.
1.8.	Написать Dockerfile который упаковывает скомпилированное / интерпретируемое приложение и все необходимые для его работы зависимости, в том числе файл конфига.
1.9.	Написать Env файл для Docker содержащий работающие примеры значений переменных среды (пункты 1.5 — 1.7) для демонстрации.
1.10.	Собрать тегированный образ Docker на основе  Dockerfile файла.
1.11.	Подключить собранный образ в Docker compose с postgresql docker образом, передав параметром путь до  Env файла.

## Структура

- `app/main.py` — периодическая проверка базы;
- `app/config.toml` — несекретные параметры подключения;
- `app/Dockerfile` — образ приложения 
- `.env.example` — рабочее окружение
- `compose.yaml` — сборка и запуск двух образов
- `db/Dockerfile` — PostgreSQL 
- `db/postgresql.conf` — настройки PostgreSQL
- `db/init-user.sh` — создание пользователя с минимальными правами;
- `run.sh` — сборка, запуск и просмотр логов.

## Quick start and reset

Запуск

```bash
./run.sh
```

Удалить контейнеры и volumes

```bash
docker compose down --volumes
```


```bash
docker build --tag rsp-pinger:1.0.0 app
docker image inspect rsp-pinger:1.0.0
```

## Проверка по заданию

Запуск с укороченным интервалом

```bash
POLL_INTERVAL_SECONDS=10 docker compose up --build --detach --wait
```

Затем стопаем базу и рестар pinger, чтобы первая проверка была неуспешной:

```bash
docker compose stop postgres
docker compose restart pinger
docker compose logs --follow pinger
```

Затем:

```bash
docker compose start postgres
```
