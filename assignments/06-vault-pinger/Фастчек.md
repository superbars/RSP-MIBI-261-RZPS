# Задание 6
## Структура

- `app/main.py` — получает секрет из Vault и проверяет PostgreSQL;
- `app/entrypoint.sh` — загружает RoleID и SecretID из защищённого Docker volume;
- `app/config.toml` — конфиг параметры PostgreSQL;
- `app/Dockerfile` — образ `rsp-vault-pinger:1.0.0`;
- `vault/init.sh` — включает AppRole, записывает секрет, политику и создаёт AppRole;
- `vault/pinger-policy.hcl` — разрешение на чтение одного секрета;
- `vault/file/` — внешний путь, подключённый к `/vault/file`;
- `db/` — PostgreSQL 18 из задания № 2;
- `compose.yaml` — PostgreSQL, Vault, инициализация Vault и pinger;
- `demo-secrets.sh` — переключение правильного и неправильного пароля;

## Запуск

```bash
./run.sh
```

Посмотреть метаданные секрета без вывода пароля:

```bash
docker compose exec \
  -e VAULT_ADDR=http://127.0.0.1:8200 \
  -e VAULT_TOKEN=dev-only-root-token \
  vault vault kv metadata get secret/pinger/database
```

Проверить AppRole и получить RoleID:

```bash
docker compose exec \
  -e VAULT_ADDR=http://127.0.0.1:8200 \
  -e VAULT_TOKEN=dev-only-root-token \
  vault vault read auth/approle/role/pinger/role-id
```

```bash

  -e VAULT_TOKEN=dev-only-root-token \
```
